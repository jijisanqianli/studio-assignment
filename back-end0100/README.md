## 一些本节任务的回答

- **设计模式**是什么

  设计模式是一套被反复使用、经过分类和总结的代码设计经验。它是解决特定问题的**方法和套路**，简单来说就是一种解决问题的模板。

- JDK 中常用的设计模式有哪些

  - 单例模式
  - 工厂模式
  - 装饰器模式
  - 迭代器模式
  - 适配器模式
  - 策略模式

- 单例模式是什么？请用 Java 写出线程安全的单例模式

  保证一个类在整个程序中**只有一个实例**，避免重复创建，逻辑统一

  ```
  public class Singleton {
      private static Singleton instance;//唯一实例真身
  
      private Singleton() {}
  
      public static Singleton getInstance() {
          // 只有实例为空时才创建，否则直接返回
          if (instance == null) {
              instance = new Singleton();
          }
          return instance;
      }
  }
  ```

- 使用工厂模式有哪些好处？ 说说它的应用场景

  - 好处：

    - **解耦**：对象创建与使用分离，业务代码不依赖创建细节；

    - **易扩展**：新增产品只需加工厂逻辑，不改旧代码；

    - **降成本**：隐藏复杂创建逻辑，降低使用成本；

    - **便维护**：统一管理对象创建，便于维护和监控。
    
  - 应用场景：
  
    - 对象创建逻辑复杂（需要多参数 / 多步骤）；
  
    - 需根据条件动态创建对象（支付系统（根据支付方式创建微信 / 支付宝 / 银联支付对象））；
  
    - 框架 / 工具类设计（屏蔽底层实现）；
  
    - 需统一管控对象创建（缓存、权限校验）。
